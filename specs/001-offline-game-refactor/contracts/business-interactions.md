# Phase 1 · 业务交互契约草案

下表名称供阅读和检索。稳定交互身份、消息关联和版本规则由 [计划 PEND-01](../plan.md#待明确事项) 定义。

| 交互 | 请求或事实携带的数据 | 结果与边界 |
|---|---|---|
| Command · 创建对局 | PVE 或 EVE、两席牌表引用、控制者配置、指定发行版本（如有） | 会话查询并校验牌表、取得快照、准备席位，再初始化核心。成功返回对局引用，失败说明对应的牌表、席位或准备原因。初始视图另由对局接口分发。 |
| Query · 读取席位或公开视图 | 对局和连接上下文 | 返回当前可见状态、状态版本及该连接可见的决策。公开观战仅可查询及接收公开更新。 |
| Command · 提交动作 | 对局和连接上下文、命令引用及依据版本、卡牌实例或目标。应答时携带决策引用及选择。 | 核心按席位、阶段及现有规则裁定。非法或失效时向提交者返回原因。重复命令至多生效一次。 |
| Event · 可见对局视图已更新 | 面向连接的状态版本、可见结算事实及可见决策 | 按发生顺序交付。出牌、等待选择和恢复结算可以产生多次更新。未公开信息只交付授权席位。 |
| Command · 请求生成 AI 行动 | 模型配置、席位观察、当前决策或行动上下文、时间预算 | 返回是否受理。模型只产出决定。 |
| Event · AI 行动已生成 | 生成的行动或选择、对应的决策上下文 | AI 玩家适配器根据当前席位状态提交正式命令。迟到响应处理细节由 PEND-01 确认。 |
| Query · 读取授权试算资料 | 对局引用、经允许的试算上下文 | 返回只读资料。试算演进隔离副本。旧 V6 可见字段的边界由 PEND-02 / PEND-03 确认。 |
| Query · 读取牌表或卡池 | 卡组引用、目标版本或卡牌查询条件 | 返回指定版卡牌、构筑预检结果、已解析牌表或只读快照。 |
| Command · 保存卡组 | 名称、指定发行版本、卡牌引用及数量 | 构筑服务重新校验。成功返回保存后的卡组引用。失败保留此前正式记录。 |
| Command · 发布卡池 | 基础发行版本、完整草稿、目标规则版本 | 校验卡牌结构、全部引用和规则支持范围。成功原子新增版本，失败返回可定位的诊断。 |
| Event · 新卡池版本已发布 | 新发行版本及其基础版本 | 在发行数据提交后通知订阅方，已开始的对局继续使用原快照。 |

层间发起方、接收方和模块映射见[四层边界图](layer-boundaries.md)。本草案为后续契约审查提供范围，PEND-01 至 PEND-03 仍待完成。
