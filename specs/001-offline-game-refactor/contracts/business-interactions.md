# 业务交互契约

## 稳定标识与传输

下表的 ID 对应[总图及两端模块图](layer-boundaries.md)。同一 ID 的方向、语义与业务含义在三处一致。稳定键为交互 ID 与契约主版本。新增可忽略字段递增次版本。删除字段或改变其含义、权限和命令效果升级主版本。连接在握手时确认主版本相同，选择双方支持的最高共同次版本。主版本不符和无共同次版本须分别返回可辨认的拒绝原因及双方声明的协议版本范围，随后关闭失败连接。协商完成前不得授权席位、接收业务请求或推送业务事件。命令和查询使用类型化请求及返回结果，事件通过相应连接通知。浏览器边界用结构化消息，可信模块可直接调用同一契约。初始契约为 1.0。

| ID · 类型 | 发起方 → 接收方 | 请求、返回或通知 |
|---|---|---|
| M01 · Command | 玩家端与观战端 → 对局 | 创建 PVE/EVE，携带请求 ID、席位配置、模型及规则和发行选择。返回已就绪会话引用或失败席位和原因。 |
| M02 · Command | 玩家端与观战端 → 对局 | 出牌、攻击、回合动作、决策回应或认输。携带命令 ID 与从授权视图取得的预期状态标记，决策回应携带决策 ID。返回受理回执或目标、行动权、过期等可辨认原因。 |
| M03 · Query | 玩家端与观战端 → 对局 | 取当前席位或公开视图，返回快照、本连接的序号与用于 M02 的不透明状态标记。Query 期间业务状态保持不变。 |
| M04 · Event | 对局 → 玩家端与观战端 | 当前连接可见的就绪、待决策、公开动作和结果。事件携带会话 ID、连接流序号与适用的不透明状态标记，可见时关联起因命令。 |
| M05 · Query | 对局 → 构筑与卡池 | 构筑服务校验双方牌表，向只读卡牌目录取得指定发行快照并返回校验结果。 |
| M06 · Query | AI 决策 → 对局 | 取得授权试算资料及同版正式规则解算器能力。对局接口按宿主登记的任务、模型身份、席位和状态基准核验。一般种子限本席观察及假设。首版登记的 V6 内部适配器可取得经核实的迁移必需字段。两类资料都只在单次内部任务的隔离副本上使用，玩家协议连接不能请求或读取。 |
| M07 · Command | 玩家端与观战端 → 对局 | 宿主启动器用原会话引用请求续接未结束的对局。对局层核验资源、记录版本哈希和原席位绑定，加载最近确认状态并重建所需连接授权。返回恢复后的会话引用或可辨认原因。视图由 M03 取得，旧端口和旧 AI 任务失效，由适配器从恢复视图准备新的任务。 |
| M08 · Query | 玩家端与观战端 → 对局 | 可信宿主从指定已确认终局记录读取只读结果或授权回放。公开投影只读公开内容。宿主确认本机操作者选择原本地真人视角并核验原席位绑定后，才可读取该席位的私有投影。回放执行前校验版本及记录完整性。 |
| M09 · Command | 玩家端与观战端 → 对局 | 可信宿主内的获准开发者或隔离验收请求复现指定确认点。校验后在隔离环境执行，返回结果或诊断。 |
| M10 · Query | 玩家端与观战端 → 对局 | 可信宿主授权开发入口读取带版本哈希的诊断记录，供宿主导出。 |
| M11 · Query | 玩家端与观战端 → 对局 | 可信启动器列出本机已确认的对局引用及状态。未结束对局可选 M07，终局可选 M08。结果仅供可信宿主的正常入口使用，不携带私有内容、未确认记录或命令回执。 |
| A01 · Query | 玩家端与观战端 → AI 决策 | 查询指定模型的可用性和版本。 |
| A02 · Command | 玩家端与观战端 → AI 决策 | 准备模型席位或请求生成行动，返回准备结果或生成受理。生成请求附请求 ID 与当前可见决策上下文。 |
| A03 · Event | AI 决策 → 玩家端与观战端 | 向原 AI 适配器通知行动已生成，回带请求 ID 和状态基准。适配器另发 M02。 |
| D01 · Query | 玩家端与观战端 → 构筑与卡池 | 查询卡池或卡组、预检导入牌表、预检草稿或导出卡组内容。返回数据或可定位诊断。 |
| D02 · Command | 玩家端与观战端 → 构筑与卡池 | 保存或导入卡组、创建或更新草稿、发布发行版。返回正式记录或校验、存储和版本错误。 |
| D03 · Event | 构筑与卡池 → 玩家端与观战端 | 发行事务提交后通知宿主维护界面新增版本。 |
| D04 · Query | 构筑与卡池 → 对局 | 查询选定规则版本支持的触发器及效果。 |

D01 预检和 D02 正式导入均按所选目标发行版校验文件完整性、卡牌 ID 是否存在以及整副牌表是否合法。构筑服务用跨发行版稳定的卡牌 ID 查目标版本，无需加载源版本或比较两个版本的卡面和效果。缺卡时返回缺失 ID 和目标发行版。D02 在写入时重新校验，成功后原子保存名称、牌表与目标发行版，失败保留原文件及既有记录。

启动器经 A01、A02 预备所选 AI 适配器，再以 M01 提交准备结果。对局会话核验并绑定对应席位，失败时宿主释放预备资源，接口无就绪事件。M07 恢复同一未结束会话，重复调用不得另建对局。M01 初始确认成功即由 M11 读到原会话，即使 M01 回执尚未送达即退出。通过 M11 找回引用后执行 M07，M01 的去重范围仍为启动器运行期。续局、回放和历史复现均先比对本次使用的每条记录的版本哈希和实际加载版本。缺少匹配资源与哈希不匹配分别返回可辨认的诊断，保留原记录并拒绝执行。M08 的只读胜负查询可直接读取已确认结果，无须加载规则或执行回放。M09、M10、M11 只在可信宿主内发起，席位或观战授权不包含这些能力。M08 的只读授权绑定终局记录、查看实例和视角。前端不得自行选择任意席位或凭旧行动端口取得私有回放。终局确认后，对局接口停止受理该局行动，向仍在线的连接发送该次回执和可见终局更新，再关闭实时连接。若未送达，重开后经 M11、M08 查看已确认终局，既不恢复行动也不重发归档回执。

同一会话的 M02 通过同一队列串行处理。进入队列后，先校验连接仍有效、目标会话尚未结束且匹配、连接具备提交该席位命令的权限。仅通过这道检查才以当前会话、授权席位和命令 ID 查找已登记的请求摘要及回执。该次请求的拒绝或确认处理完成后才处理下一条命令。持久化模块的独占写入者覆盖所有会话提交入口。之后按下表处理。

| 提交情形 | 原请求反馈 | 业务状态及事件 |
|---|---|---|
| 未结束会话中同席位同 ID 同内容，已有确认回执 | 返回原回执，即使原修订号或决策已失效。 | 无新增结算、修订或可见事件。 |
| 同席位同 ID 同内容，仅有此前规则拒绝时登记的摘要 | 按当前确认局面重新裁定，使用原命令内容。 | 仍被拒绝时，无新增结算、修订或可见事件。若当前规则允许，按正常受理流程确认一次。 |
| 同席位同 ID 改内容 | 返回命令 ID 冲突。 | 无新增结算、修订或可见事件。 |
| 目标会话已结束或通过只读终局授权提交动作 | 结束的实时连接不可提交，终局只读授权不接受命令。不得查询或返回归档回执。 | 无新增结算、修订或可见事件。 |
| 新 ID 重交已完成决策 | 返回决策已失效。 | 无新增结算、修订或可见事件。 |
| 未授权、其他席位冒用或授权已撤销 | 授权检查拒绝，活动连接得到未授权反馈。已关闭连接由宿主报告连接或授权失效。两种情况下均不查询或交付原回执，也不确认其存在。 | 无新增结算、修订或可见事件。 |

无确认回执的命令按原请求和当前确认局面检查。对于已结束的原待决策，返回决策已失效。通过授权但因规则被拒的命令，在返回规则拒绝前独立持久化该去重键的请求摘要，仅用于同 ID 内容一致性检查。历史确认点记录当时已生效的摘要范围，后续单独登记的拒绝摘要不回写旧确认点。拒绝原因随当次响应返回，权威状态、确认点、正式回执及可见事件维持原样。摘要写入失败时返回存储失败。合法决策只能消费一次。对局层在该会话队列内以最新确认状态计算候选，再通过同一 SQLite 事务提交权威快照、历史记录和命令回执。后续命令基于该次处理后实际确认的状态重新检查。事务成功后才发布可见事件并返回正式回执。事务失败时保留上次确认进度。重启直接载入最近快照并核对原席位绑定，重新授权连接。旧模型任务失效；适配器可从恢复视图发起新任务。状态变化、选择取消或席位失效后，迟到 AI 结果由适配器丢弃，核心再次验证提交的修订号与决策 ID。客户端看到序号缺口时通过 M03 重取当前快照，并从快照序号接收后续更新。观战与各席位各用自己的有序流，流序号不暴露私有事件数量。M02 的不透明状态标记指向核心修订，M03 和 M04 不输出全局修订计数。标记按连接授权范围发放，已确认回执的重试仍先按原请求查找确认结果。

## 业务不变量与反例

| 不变量 | 裁定方及失败后的状态 | 验收反例 |
|---|---|---|
| 当前有权席位持有仍有效的决策 | 对局接口与核心拒绝，权威状态及待决策进度保持。 | 观战提交动作，另一席应答待决策，或有权席提交失效选择。 |
| 只有授权视图可离开宿主 | 对局接口先投影，授权由可信宿主发放。失效连接关闭，观战只收公开状态。 | 第三方连接要求对手私有视图、内部试算或已经撤销的席位，核对返回和事件不含受保护数据。 |
| 每个命令至多执行一次，每个决策只消费一次 | 对局接口返回原确认回执或冲突。规则拒绝后的原样重试由核心按当前局面裁定。所有未受理的请求保持局面修订与可见事件不变。 | 并发提交相同命令或以不同 ID 竞争同一修订。另从同一待决策先提交无效选项，再用新命令完成选择，重启后验证原样重试返回决策失效、同 ID 改内容返回冲突。 |
| 试算按内部任务授权并与正式对局隔离 | 默认使用本席观察和假设样本，登记的 V6 任务另获迁移必需字段。试算副本使用独立随机流，A03 仅带行动意图及关联标识。 | 普通模型任务与未获准请求读不到内部隐藏字段。对登记的 V6 核对获准字段、输出范围及试算前后权威状态一致。 |
| 确认状态、命令回执及历史一致 | 对局层在同一事务确认。重启直接续局。独立环境可读取历史确认点并复算，原会话存储保持原样。 | 应答确认后、回执送出前退出，重启后重试取得原结果且无重复结算。从历史等待点复算并核对原记录。 |
| 对局持有开局快照 | 会话和核心保留原版本，发布事务只新增版本。 | 活跃对局中发布效果变更，当前局沿用旧效果，新局可选择新版。 |
| 发行版原子提交，卡组原子保存 | 构筑存储和 SQLite 发布模块分开提交。失败时原记录仍在，版本列表保持，且无成功通知。 | 发布缺失跨卡引用或模拟写入中断，检查版本数和发布事件。模拟卡组写失败后读回原卡组。 |
| 旧回放偏差有可核验归因 | 回放模块以版本和随机输入验证新版。旧版已知随机限制在样本记录中关联参考文件、条件和观察结果。 | 以含随机结算样本重放到同一终局，再移除匹配版本检查明确错误。 |
