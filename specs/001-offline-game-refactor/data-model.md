# 数据模型 · 《临界》

下表以 `实体.字段` 标明实施任务引用的键。对局权威数据在可信宿主内，视图、回放与试算副本通过各自边界交付。

| 实体及字段 | 唯一写入者 | 读取范围与生命周期 |
|---|---|---|
| `Session.id`、`Session.status`、`Seat.binding` | 本地会话 | 每场唯一会话 ID。两席绑定真人或 AI，创建期间为准备中，全部准备成功后进入就绪，失败则终止并清除临时绑定。对局接口核验绑定，前端只能看到自身及公开席位信息。 |
| `Match.revision`、`Match.snapshotRef` | 对局核心 | 每次已接受并改变权威状态的动作递增修订号。开局固定规则版本和不可变卡池发行版，贯穿对局、回放和试算种子。完整状态仅内部可读。 |
| `Decision.id`、`Decision.owner`、`Decision.continuation` | 对局核心 | ID 在会话内唯一。核心保存恢复位置和待结算进度。拥有者看到候选项与限制，恢复位置留在核心。合法消费、规则取消或会话结束使其失效。 |
| `CommandReceipt.key`、`CommandReceipt.result` | 对局接口 | 会话、授权主体（席位或创建发起者）、命令 ID 构成去重键。确认受理时保存请求摘要和原结果，回执与其引起的状态变更同事务提交，重连及重启后可返回原结果。通过授权但因规则被拒时持久化去重键与请求摘要。原样重试按当前确认局面裁定，改变内容时返回冲突。去重记录会话结束时归档。创建请求在启动器运行期按发起者与命令 ID 去重。 |
| `View.sequence`、`View.scope` | 对局接口 | 每个连接一条连续序列，序号从初始快照起步。席位视图和公开视图分开投影；前端持有只读副本，重连以新快照重新开始。 |
| `ModelJob.requestId`、`ModelJob.basis`、`ModelJob.result` | AI 决策层 | 请求 ID 由适配器生成，模型任务关联会话、席位、修订号和可选待决策 ID。结果仅投递给原适配器，适配器持有待提交副本。提交、取消或变更触发失效。 |
| `SimulationSeed.fields` | 对局接口生成种子，模型只写隔离副本 | 仅获准模型的对应席位可读。范围见下文。种子绑定单次任务，到期即销毁。 |
| `Card.id`、`Release.id`、`Release.rulesVersion` | SQLite 发布模块 | 同一张卡的 ID 跨发行版稳定，卡面或效果更新沿用该 ID。不同卡牌使用不同 ID，已移除卡牌的 ID 不复用。发行版完整写入后不可变。目录按版本读取，构筑和对局按指定发行读取。历史版本供回放和旧卡组引用。 |
| `Draft.baseRelease`、`Draft.content` | 卡池编辑器 | 从已发行版本派生，维护者在宿主编辑与预检。预检只给诊断，发布读取并重新校验，失败保留编辑内容。 |
| `Deck.id`、`Deck.releaseId`、`Deck.entries` | 用户卡组存储 | 独立于卡池数据库。正式记录含名称、发行版本、稳定卡牌 ID 与正整数数量，整副校验后提交。保存失败保留上一版本和本轮编辑。导入及开局均按目标发行校验。跨版本导入按稳定 ID 解析所有卡牌并校验整副牌表，保存时引用所选目标发行版。 |
| `Recovery.latest`、`Recovery.history` | 对局层持久化模块 | 每次确认以同一事务保存权威快照、历史条目与命令回执。快照包含席位绑定、规则及卡池版本、结算进度、待决策项和随机状态。重启直接加载最近快照。确认状态须保存随机候选的原决策 ID、有序候选、结算位置及后续随机状态。原随机输入及完整记录仅供可信宿主持久化模块和获准的隔离复现读取。席位通过视图取得公开状态、本席私有结果及本席有权响应的候选。对手和观战视图仅显示各自可见的结果与公开区域变化，不提供私有候选流、抽样顺序或随机输入。 |
| `Replay.versions`、`Replay.inputs` | 回放模块 | 保存规则、卡池版本、初始条件、有序接受动作与随机输入或结果。由宿主本地回放流程读取，前端按普通视图权限观看。 |
| `FrontendPackage.manifest`、`Installation.key`、`Installation.state` | 启动器安装器 | 格式见[前端包规范](contracts/frontend-packages.md)。安装记录与入口内容原子提交，仅已验证的版本可启动。卸载移除对应安装及其内容。 |
| `FrontendConnection.capability` | 对局接口 | 授权绑定运行实例、端口、会话和席位或观战范围。宿主选择授权，运行停止、导航、更换席位或会话结束时撤销。 |

## 解算器与 AI 试算字段

模型只能读取所绑定席位的公开状态和本席私有观察，包括己方手牌、可消费的待决策候选，以及公开战场、行动阶段和公开弃牌。未知对手手牌及未抽牌顺序等隐藏数据以假设样本补足。按该局固定的规则和卡池版本调用正式解算器，在副本上使用独立随机流。模型也可以直接从席位观察生成行动。若旧 V6 样本证明依赖真实隐藏状态，记录字段和影响样本，将其标为待退役，以符合约束的新模型作为首版优先方案。真实随机源、权威回执、连接和存储句柄留在各自所有者。
