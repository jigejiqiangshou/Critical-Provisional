# Phase 1 · 概念数据模型

字段为业务含义，持久化结构及标识格式留待计划待办确认。

| 实体 | 所在层与责任模块 | 关键数据、关系和验证 |
|---|---|---|
| 对局会话与席位绑定 | 对局层 · 本地会话 | 对局引用、两个席位的控制者、所选牌表、准备结果。准备成功后进入就绪。失败返回席位或配置原因。 |
| 对局状态 | 对局层 · 核心 | 固定卡池快照与规则版本、当前阶段、行动权、随机输入、双方区域、终局。动作由核心验证并推进。 |
| 卡牌实例及单位 | 对局层 · 核心 | 对局内引用、卡牌定义引用、所在区域与单位状态。一张卡牌定义可对应多张对局实例。 |
| 待决策项与待结算效果 | 对局层 · 核心 | 决策引用、归属席位、候选、选择限制、恢复位置。产生后等待合法应答，随后完成或按旧版流程取消。 |
| 可见视图与更新 | 对局层 · 统一接口 | 投影对象、状态版本、事件顺序及可见数据。玩家端持有副本。观战使用公开投影。 |
| 模型请求与决定 | AI 决策层 · 模型与试算 | 席位观察、对应的行动或决策上下文、时间预算、候选决定。AI 玩家适配器将决定转换为正式命令。 |
| 卡牌定义、发行版本及快照 | 构筑与卡池层 · 目录与发布 | 稳定卡牌引用、版本化卡面与结构化效果。版本引用基础版本与规则能力。对局固定一份只读快照。 |
| 编辑草稿 | 构筑与卡池层 · 编辑器 | 基础发行版、改动和校验诊断。校验通过并完整写入后产生发行版。失败保留可继续编辑的草稿。 |
| 用户卡组 | 构筑与卡池层 · 卡组存储 | 卡组引用、名称、卡牌引用与数量、卡池版本。保存和开局分别依据所选版本校验。 |
| 回放记录 | 对局层 · 回放模块 | 初始状态、卡池与规则版本、动作、随机结果和终局。缺少匹配版本时提供明确诊断。 |

最终字段级读写和生命周期矩阵见计划 PEND-02。标识、版本、顺序和关联规则见 PEND-01。跨层禁止性约束及反例见 PEND-03。
